Limetry ships two first-party SDKs with the same evaluate contract:

| Language | Package | Install |
| --- | --- | --- |
| TypeScript | [`@limetry/sdk`](https://www.npmjs.com/package/@limetry/sdk) | `npm install @limetry/sdk` |
| Python | [`limetry`](https://pypi.org/project/limetry/) | `pip install limetry` |

Point `baseUrl` / `LIMETRY_BASE_URL` at your evaluation server (`http://localhost:3810`
or your origin). Use `LIMETRY_BEARER_TOKEN` / `LIMETRY_API_KEY` unless you issue
your own API tokens on that node.

## Quick evaluate

TypeScript:

```typescript
import { createRemoteEngine } from "@limetry/sdk"

const engine = createRemoteEngine({
  baseUrl: "http://localhost:3810",
  apiKey: process.env.LIMETRY_BEARER_TOKEN,
})
const decision = await engine.evaluateAction(intent)
```

Python:

```python
from limetry import create_remote_engine

engine = create_remote_engine(base_url="http://localhost:3810")
decision = engine.evaluate_action(intent)
```

`decision` is `allow`, `deny`, or `approval_required` (plus `approved` / `reasons`).

<Tip>
Send only fields needed for policy. Prefer `auditMode: "minimal"` /
`audit_mode="minimal"` unless you need forensics. See
[Minimize audit data](/docs/server/data-minimization).
</Tip>
